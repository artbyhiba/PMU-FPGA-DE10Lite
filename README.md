# PMU FPGA DE10-Lite Project

This project implements FPGA-based PWM control, ADC interfacing, and display control for DE10-Lite board.

## Features
- PWM signal generation (10-bit resolution)
- Switch debouncing
- 7-segment display driver
- ADC interface
- LED brightness control via PWM

## Tools
- Intel Quartus Prime
- Verilog HDL
- VHDL
- ModelSim Simulation

## Hardware
- Intel DE10-Lite FPGA Board
