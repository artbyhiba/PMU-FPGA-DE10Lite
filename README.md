# FPGA Based PMU Implementation (DE10 Lite MAX10)

## Project Overview
This project implements a real-time Phasor Measurement Unit (PMU) using FPGA hardware acceleration and embedded software processing.

The system performs real-time signal acquisition, filtering, phasor estimation, and frequency tracking.

---

## Hardware Platform
- Intel MAX10 FPGA (DE10 Lite)
- Embedded ADC
- GPIO Interface
- Seven Segment Display
- PWM Signal Generation

---

## Software & Tools
- MATLAB – Signal Processing & Filter Design
- Verilog HDL – FPGA Hardware Modules
- Quartus Prime – FPGA Development
- Nios II – Embedded Software Development

---

## Implemented Algorithms
- Butterworth IIR Filtering
- RMS and Phase Estimation
- DFT Based Phasor Extraction
- Frequency Estimation

---

## System Flow
Analog Signal → Filtering → ADC → FPGA Processing → PMU Algorithm → Display / Output

---

## Key Learning Outcomes
- Hardware Software Co Design
- FPGA Signal Processing
- Embedded System Development
- Power System Monitoring
